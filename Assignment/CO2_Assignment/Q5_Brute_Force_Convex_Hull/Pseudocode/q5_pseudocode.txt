Q5 - BRUTE-FORCE CONVEX HULL: PSEUDOCODE (derived from the "one side of the line" principle)

1. Two points P1=(x1,y1), P2=(x2,y2) define a line  a*x + b*y = c  where
        a = y2 - y1,   b = x1 - x2,   c = x1*y2 - y1*x2
2. For another point R=(x,y) compute  s = a*x + b*y - c
        s > 0 : R is on one side;   s < 0 : R is on the other side;   s = 0 : R is on the line.
3. Segment P1P2 is a hull edge if no two other points give opposite signs.

ConvexHull(Points)
  P <- remove duplicate points;  if |P| < 3 return P
  edges <- empty
  for i <- 0 to n-2
      for j <- i+1 to n-1
          sawPositive <- false; sawNegative <- false; ok <- true
          for k <- 0 to n-1, k != i, k != j
              s <- a*xk + b*yk - c
              if s > 0 then sawPositive <- true
              if s < 0 then sawNegative <- true
              if s = 0 and Pk lies OUTSIDE segment PiPj then ok <- false; break   // PiPj is only part of a longer edge
              if sawPositive and sawNegative then ok <- false; break              // early exit: points on both sides
          if ok then add edge (Pi,Pj)
  vertices <- end points of accepted edges
  sort vertices counter-clockwise by atan2(y - cy, x - cx) around their centroid -> boundary polygon
  return vertices

WORK: n(n-1)/2 candidate lines x up to (n-2) side tests = n(n-1)(n-2)/2 tests in the worst case -> O(n^3).

CORRECTNESS ARGUMENT (summary)
  If all other points lie in one closed half-plane of line PiPj, the whole point set is inside that half-plane,
  and since Pi and Pj belong to the set, the segment PiPj lies on the boundary of the smallest convex region
  containing the set - so it is on the hull.  If points exist on both sides, the segment passes through the
  interior of the set's convex hull, so it cannot be a boundary edge.
