Q4 - CONVENTIONAL AND STRASSEN MATRIX MULTIPLICATION: PSEUDOCODE

CONVENTIONAL BLOCK DECOMPOSITION (Student B): split A, B, C into four n/2 x n/2 blocks
  C11 = A11 B11 + A12 B21        C12 = A11 B12 + A12 B22
  C21 = A21 B11 + A22 B21        C22 = A21 B12 + A22 B22          -> EIGHT block multiplications  T(n) = 8T(n/2) + O(n^2) = Theta(n^3)

STRASSEN'S SEVEN PRODUCTS
  M1 = (A11 + A22)(B11 + B22)     M2 = (A21 + A22) B11            M3 = A11 (B12 - B22)       M4 = A22 (B21 - B11)
  M5 = (A11 + A12) B22            M6 = (A21 - A11)(B11 + B12)     M7 = (A12 - A22)(B21 + B22)
  C11 = M1 + M4 - M5 + M7         C12 = M3 + M5                   C21 = M2 + M4              C22 = M1 - M2 + M3 + M6
  T(n) = 7T(n/2) + 18 (n/2)^2 = Theta(n^log2(7)) = Theta(n^2.807)

Strassen(A, B, cutoff)
  n <- size;  if n <= cutoff then return Conventional(A, B)
  split into blocks;  compute the 10 block additions/subtractions, then M1..M7 by RECURSIVE calls, then the 8 combining additions
  return assembled C

Padding: if n is not a power of two, pad A and B with zero rows/columns up to m = next power of two, multiply, and keep the top-left n x n block.
  Zero padding does not change the product: [A 0; 0 0] x [B 0; 0 0] = [AB 0; 0 0].   Cost: m^3 instead of n^3 work in the worst case (up to 8x).
EXPERIMENTS (Student A): operation counts, pure-Python timings (cut-offs 16/32), cut-off sweep, padding cost, NumPy timings 256..2048.
