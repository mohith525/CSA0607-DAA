Q2 - MERGE SORT AND QUICK SORT: PSEUDOCODE

MergeSort(A)
  if |A| <= 1 then return A
  mid <- |A| / 2
  L <- MergeSort(A[0..mid-1]);  R <- MergeSort(A[mid..])           // ALWAYS an equal split -> height ceil(log2 n)
  return Merge(L, R)                                                // compares heads of L and R, n-1 comparisons at most

QuickSort(A)   PIVOT STRATEGY = FIRST ELEMENT OF THE SUBARRAY
  if |A| <= 1 then return A
  p <- A[0]
  left <- empty;  right <- empty
  for each x in A[1..]:   comparisons++;   if x < p then append x to left else append x to right
  record partition sizes (|left|, |right|);  depth tracked by the recursion
  return QuickSort(left) + [p] + QuickSort(right)

TEST INPUTS FOR PARTITION QUALITY
  Balanced input (Student A): BalancedOrder(S) = [median of S] + BalancedOrder(lower half) + BalancedOrder(upper half).
        With the first element as pivot, every partition splits exactly in half (e.g. n=7: 4 2 1 3 6 5 7).
  Severely unbalanced input (Student A): already ascending (or descending) data: the first element is the minimum (maximum),
        so partitions are (0, n-1): depth n and n(n-1)/2 comparisons.
  Also: random data, all-equal data, random pivot, and an oracle 10th-percentile pivot (10:90 split).

RECURSION-TREE VIEW (Student B)
  Merge sort : T(n) = 2T(n/2) + n  ->  height log2 n, n work per level  ->  Theta(n log n) always.
  Quick sort : T(n) = T(k) + T(n-1-k) + (n-1) for split k.  Balanced: height log2 n -> Theta(n log n).
               Repeated (0, n-1) splits: T(n) = T(n-1) + n - 1 -> n(n-1)/2 -> Theta(n^2); height n.
               Constant ratio split, e.g. 90:10: height log_{10/9} n -> still Theta(n log n), larger constant.
