Q4 - BRUTE-FORCE CLOSEST PAIR: PSEUDOCODE

CANDIDATE PAIRS
  Pair (i,j) and pair (j,i) are the same pair, and (i,i) is meaningless -> examine only i < j.
  Number of unique pairs = (n-1) + (n-2) + ... + 1 = n(n-1)/2 = C(n,2)   (quadratic growth)

ClosestPair(D[0..n-1])
  best <- infinity;  pairs <- 0;  distCalcs <- 0
  for i <- 0 to n-2
      for j <- i+1 to n-1
          pairs++
          d <- (xi - xj)^2 + (yi - yj)^2           // squared distance: no square root needed to compare
          distCalcs++
          if d < best then best <- d; bestPair <- (i,j)
  return sqrt(best), bestPair

EXPERIMENT: n = 10, 100, 500, 1000, 2000, 3000 uniform random points; record pairs, distance calculations, time.
ACCEPTABLE RESPONSE TIME (defined by me): 1 second on this machine (pure Python).
