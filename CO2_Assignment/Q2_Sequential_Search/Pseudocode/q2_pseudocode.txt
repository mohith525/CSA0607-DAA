Q2 - SEQUENTIAL SEARCH: PSEUDOCODE

SequentialSearch(Records[0..n-1], ToolID)
  comparisons <- 0
  for i <- 0 to n-1
      comparisons++
      if Records[i].ToolID = ToolID then return (i, comparisons)
  return (not found, comparisons)

EXPERIMENT DESIGN
  List sizes n = 50, 200, 1000, 5000, 20000 (records: ToolID, TechnicianID, IssueTime, WorkBay)
  For each n measure comparisons for:
     - successful search, FIRST record          (best case, expected 1)
     - successful search, MIDDLE record         (expected about n/2)
     - successful search, LAST record           (worst successful, expected n)
     - 500 random successful searches, average  (expected about (n+1)/2)
     - UNSUCCESSFUL search (tool not issued)    (expected exactly n)

OPERATING-BOUNDARY MODEL
  comparisons per second = (lookups per second) x (average comparisons per lookup)
  Sequential search average cost = (n+1)/2 for hits, n for misses.
  Alternative: hash index on ToolID -> about 1 comparison per lookup; update on issue/return in O(1).
